After · publication has one owner

Experiment keeps its sequential lifecycle
ArtifactStore owns publication
Reject collisions before replacement
Keep model and Artifact Manifest together
Keep incomplete saves unpublished
Run Ledger mirrors only after publication
Problem
A same-second version collision can replace an earlier Artifact before the reporting mirror rejects the duplicate; an interrupted overwrite can mix a new model with an old Artifact Manifest.
Solution
Give the existing Artifact module responsibility for safe publication, while Experiment keeps evaluation order and uses collision-resistant identity allocation.
Depth
Callers no longer need to guard filesystem reuse or partial saves themselves.
Deletion test
Keep ArtifactStore: deleting it would scatter layout and serialization into training and inference; concentrate publication rules there too.
Tests
Existing tests cover one round-trip; add duplicate-save and interrupted-save checks, then reload every Sweep Artifact after the final iteration and compare its recorded metrics.
Seam
Use the existing filesystem implementation in temporary directories; a second storage adapter is not justified.
  • Locality: publication rules stay together
  • Leverage: training and inference share guarantees
  • Tests cross the existing interface
Preserves ADR 0002. Disk remains authoritative; failed mirroring does not invalidate a published Artifact. Changing the timestamp alone is a smaller fix, but leaves publication integrity to callers.

Problem
Sweep can describe parameter changes that never reach Experiment, while configuration failures vanish from its results and reported total.
Evidence
Its own example uses model.learning_rate, but learning_rate is top-level; the nested model ignores the extra field.
Solution
Make Sweep own the correspondence between requested combinations, effective training configurations, and outcomes; leave presentation and exit behavior with the CLI.
Deletion test
Keep Sweep: deleting it would move Cartesian products and failure continuation back into the CLI; remove the permissive helper behavior, not the earned module.
Tests
The existing test runs two successful Experiments; add unknown paths, mismatched descriptions, invalid combinations, empty searches, and failure followed by success through the Sweep interface.
Seam
Reuse TrainingDataSource and Run Ledger, each with production and test adapters; do not add an executor seam.
  • Locality: search accounting stays together
  • Leverage: every combination is accounted for
  • Tests verify effective Experiment configurations
Preserves ADR 0002. Experiment still owns its sequential lifecycle. Fixing the misleading example is a small correction; making ignored inputs and missing outcomes impossible is the deepening opportunity.

A later save can invalidate the model behind an already completed Training Run, so giving ArtifactStore publication guarantees protects the project's authoritative record at an existing seam.
