gonzo-pit-strategy: architecture explorer

Three programs share one Postgres database: gonzo-load provisions it, dbt build turns the raw tables into a training dataset, and gonzo-train trains against that and writes a self-describing Artifact that inference loads with no database at all. Modules is the import graph of src/gonzo_pit_strategy/. Flows walks each program step by step, tagged with the credential path it runs under. dbt lineage is the model DAG from the Jolpica source tables to prep_training_dataset. Click a box for detail; click a symbol to expand it. A developer tool, not part of the package, and hand-written: nothing pins it to the source tree yet.
